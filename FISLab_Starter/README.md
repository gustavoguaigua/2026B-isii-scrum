# FIS-Lab Starter - ICCD632

Proyecto base para el taller Scrum de la Semana 5.

## Objetivo
El repositorio NO contiene la solución. Los Scrum Teams deben definir el Product Goal, Product Backlog, criterios de aceptación y el microincremento.

## Ejecutar pruebas
```bash
mvn test
```

## Estructura sugerida
- `docs/PRODUCT_GOAL.md`: objetivo común del producto.
- `docs/DEFINITION_OF_DONE.md`: DoD común de los tres Scrum Teams.
- `docs/DECISION_LOG.md`: decisiones importantes.
- GitHub Issues/Projects: Product Backlog recomendado.

Scrum no prescribe GitHub, historias de usuario, TDD ni Maven. Son herramientas/prácticas usadas en este laboratorio.
